# Creative intake

Use this only when the user's idea lacks information that materially changes the
font. Do not repeat questions the user already answered. Ask at most three at a
time, in ordinary language.

## Highest-value questions

1. **Feeling and medium:** “What should it feel like, and what made the marks—ballpoint, brush, marker, pencil, cut paper, pixels, metal, something else?”
2. **Use:** “Where will it live—logo, headlines, packaging, captions, long text, game/UI, or personal handwriting?”
3. **Behavior:** “Should it prioritize legibility or personality, and should letters connect like handwriting or stand independently?”

Ask for reference images only when they will materially improve the result. Have
the user identify whether each reference is their own handwriting/artwork,
structural guidance, or mood inspiration.

If the user wants help inventing the idea, offer three meaningfully different
directions. Vary the underlying logic, not just adjectives—for example:

- fast monoline ballpoint with restrained loops;
- blunt felt-tip lettering built from compressed ovals;
- irregular cut-paper forms with sharp countershapes.

## Synthesize a brief

Before generation, reduce the discussion to these decisions:

- working name;
- intended use and viewing size;
- first-pass character set;
- source medium and texture;
- skeleton: wide/narrow, upright/slanted, round/angular;
- stroke behavior: monoline/contrast, pressure, terminals;
- rhythm: orderly, hurried, bouncy, mechanical, formal;
- joining behavior and baseline;
- legibility target;
- palette for the specimen only;
- explicit avoid list;
- reference-image roles.

If the user already authorized experimentation, make reasonable assumptions,
state the brief concisely, and proceed. Do not stop for approval of a reversible
first atlas unless a missing choice would create a substantially different font.

## Repertoire defaults

- Fast proof: uppercase `A–Z` and space.
- Display release: uppercase, lowercase, `0–9`, basic punctuation.
- Text family: expanded Latin, diacritics, symbols, kerning, hinting, multiple
  weights, and language testing. This is a larger type-design project and should
  not be implied by a successful 26-glyph proof.
